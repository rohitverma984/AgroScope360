CFO Financial & MACC Calculation Methodology

All portfolio metrics are computed deterministically by prototype/core/investment_optimizer_service.py and cross-referenced against data/05_scenarios/decarbonisation_levers.csv:

  • 10-Year Net Present Value (NPV): NPV = -CAPEX₀ + Σ [ (Annual_OPEX_Savings_t + ETS2_Carbon_Shield_t) / (1 + WACC)^t ] for t = 1..10.
  • Internal Rate of Return (IRR): Binary bisection solver finding the discount rate r* where NPV(r*) = 0.
  • Hurdle Rate Multiple: (NPV_10y + Allocated_CAPEX) / Allocated_CAPEX benchmarked against Apetit's 8.0% corporate WACC.
  • Multi-Objective Knapsack Score: Weighted composite utility combining GHG abatement intensity (tCO₂e / €10k), CMIP6 drought adaptation score, SBTN freshwater P-runoff score, 10-year cash flow ratio, and operational readiness.
