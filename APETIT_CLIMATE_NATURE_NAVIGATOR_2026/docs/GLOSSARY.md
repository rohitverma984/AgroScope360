# Glossary

| Term | Meaning |
|---|---|
| Scope 1 / 2 / 3 | Direct emissions / purchased energy / value-chain emissions (GHG Protocol) |
| Location- vs market-based Scope 2 | Grid-average factors vs contractual instruments (guarantees of origin, residual mix) |
| GoO | Guarantee of origin: certificate proving 1 MWh of renewable electricity |
| Residual mix | Emission factor of electricity left after all GoOs are claimed |
| FLAG | Forest, Land and Agriculture: land-based emissions and removals (SBTi) |
| LUC / dLUC | Land-use change / direct land-use change |
| LSR | GHG Protocol Land Sector and Removals Standard (effective 2027) |
| SBTi | Science Based Targets initiative (climate targets) |
| SBTN | Science Based Targets Network (nature targets) |
| TNFD / LEAP | Taskforce on Nature-related Financial Disclosures / Locate–Evaluate–Assess–Prepare |
| ESRS E1/E3/E4 | EU sustainability reporting standards: climate / water / biodiversity |
| EUDR | EU Deforestation Regulation |
| NGFS | Network for Greening the Financial System (climate scenarios) |
| SSP1-2.6 / 2-4.5 / 5-8.5 | Shared Socioeconomic Pathways (low / middle / high emissions) |
| PCF / PACT | Product carbon footprint / WBCSD Partnership for Carbon Transparency data-exchange format |
| EEIO | Environmentally extended input-output (spend-based) factors |
| WTT / WTW | Well-to-tank / well-to-wheel |
| tkm / pkm | Tonne-kilometre / passenger-kilometre |
| MACC | Marginal abatement cost curve |
| GDD | Growing degree days (base 5 °C) |
| PET | Potential evapotranspiration |
| Organic soil | Peat or mull soil (> 20 % organic matter); drained organic soils emit large amounts of CO2 |
| Vining peas | Fresh green peas harvested for freezing (tenderometer decides harvest timing) |
| Rypsi / rapsi | Turnip rape / oilseed rape |
| Sopimusviljely | Contract farming |
| Kantvik | Apetit's oilseed mill in Kirkkonummi |
| Säkylä | Apetit's frozen-food plant, next to a large clear lake (Pyhäjärvi) |
| Odlingsdata / gröda / skördeår / levererad mängd / kvävegiva / bevattnad | Swedish: cultivation data / crop / harvest year / delivered amount / N application / irrigated |
| NCV | Net calorific value: energy content of a fuel excluding latent heat of water vapour (MWh per t or per litre) |
| GLEC Framework | Global Logistics Emissions Council method for transport emissions (tkm × factor per mode) |
| Ro-Pax | Roll-on/roll-off passenger ferry that also carries trucks and trailers (e.g. Finland–Germany/Sweden routes) |
| VEMALA | SYKE's national nutrient-load model for Finnish catchments |
| Tenderometer | Instrument measuring pea tenderness; decides the harvest day of vining peas |
| Voronoi polygons | Areas closest to each seed point; used here to draw synthetic catchments |
| HS code | Harmonised System customs code; defines EUDR product scope (Annex I) |
| GRI 303 | Global Reporting Initiative standard on water and effluents |
